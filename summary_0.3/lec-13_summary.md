제공해주신 강의 내용은 **선형 분류기(Linear Classifier)**의 기초부터 **서포트 벡터 머신(SVM)**의 원리, 최적화, 그리고 **커널(Kernel) 기법**까지 다루고 있습니다. 주요 내용을 요약하면 다음과 같습니다.

### 1. 선형 분류기 (Linear Classifier)의 기초
*   **정의:** 데이터를 두 개의 클래스(Positive/Negative)로 구분하는 직선(또는 초평면, Hyperplane)을 찾는 분류기입니다.
*   **결정 경계 (Decision Boundary):**
    *   $W^T X + B = 0$ 형태로 정의됩니다.
    *   $W$ (Weight vector): 직선에 수직인 벡터로, 직선의 방향을 결정합니다.
    *   $B$ (Bias): 절편으로, 직선의 위치를 이동시킵니다.
*   **분류 방법:** 새로운 데이터 $X$에 대해 $W^T X + B$를 계산하여 그 결과의 부호(+, -)에 따라 클래스를 판별합니다.
*   **거리 계산:** 점과 직선 사이의 최단 거리(수직 거리)는 투영(Projection) 공식을 통해 계산하며, 이는 분류의 확실성(신뢰도)을 나타내는 지표가 됩니다.

### 2. 서포트 벡터 머신 (SVM)의 개념 및 목표
*   **최적의 구분선:** 데이터를 단순히 나누는 것을 넘어, **마진(Margin)을 최대화**하는 선을 찾는 것이 목표입니다.
    *   **마진(Margin):** 결정 경계와 가장 가까운 데이터 포인트(서포트 벡터) 사이의 거리입니다.
    *   마진이 클수록 새로운 데이터에 대한 일반화 성능이 좋습니다.
*   **서포트 벡터 (Support Vectors):**
    *   마진의 경계($W^T X + B = \pm 1$)에 위치한 데이터 포인트들입니다.
    *   실제 결정 경계의 모양을 결정하는 핵심적인 데이터들입니다.

### 3. SVM의 수학적 정식화 (Optimization)
*   **조건:** 모든 데이터 포인트가 올바른 방향으로 마진 바깥에 위치해야 합니다.
    *   수식: $Y_i (W^T X_i + B) \ge 1$ (여기서 $Y_i$는 클래스 레이블로 +1 또는 -1)
*   **목적 함수 (Objective Function):**
    *   마진($M = \frac{2}{||W||}$)을 최대화하는 것은 $||W||$를 최소화하는 것과 같습니다.
    *   따라서, **$\frac{1}{2}||W||^2$를 최소화**하는 2차 최적화 문제(Quadratic Optimization Problem)로 귀결됩니다.

### 4. 듀얼 폼 (Dual Form)과 서포트 벡터의 성질
*   **Primal vs Dual:** 원래의 문제(Primal form)를 듀얼 폼(Dual form)으로 변환하여 풀 수 있습니다.
*   **$W$의 표현:** 최적의 $W$는 데이터 포인트들의 선형 결합($\sum \alpha_i Y_i X_i$)으로 표현될 수 있습니다.
*   **희소성 (Sparsity):**
    *   **서포트 벡터**인 데이터만 $\alpha_i > 0$ 값을 가지며, 나머지 데이터는 $\alpha_i = 0$입니다.
    *   즉, 결정 경계는 오직 서포트 벡터들에 의해서만 정의됩니다.
*   **예측:** 새로운 데이터의 분류는 전체 데이터가 아닌, 서포트 벡터들과의 내적(Inner Product)을 통해 계산됩니다.

### 5. 비선형 SVM과 커널 트릭 (Kernel Trick)
*   **문제점:** 원래 차원에서는 선형으로 분리할 수 없는(Linearly Inseparable) 데이터가 존재할 수 있습니다.
*   **해결책 (매핑):** 데이터를 더 높은 차원의 공간으로 매핑($\Phi(X)$)하면 선형 분리가 가능해질 수 있습니다.
*   **커널 트릭 (Kernel Trick):**
    *   고차원으로 데이터를 직접 변환하여 내적을 계산하는 것은 연산량이 매우 많습니다.
    *   대신, 고차원 공간에서의 내적 값을 직접 계산해주는 함수인 **커널($K(X, Y)$)**을 사용합니다.
    *   이를 통해 복잡한 고차원 변환 과정 없이 효율적으로 비선형 결정 경계를 찾을 수 있습니다.
