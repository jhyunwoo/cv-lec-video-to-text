### 강의 요약: 신경망 학습의 실제와 주요 기법

**1. 학습 알고리즘 및 랜덤성(Randomness) 관리**
*   **학습의 한계:** 훈련 오차(Training Error)가 항상 0으로 수렴하지 않으며, 로컬 최적점(Local Optima)에 빠지거나 진동할 수 있음. 하지만 적절한 하이퍼파라미터와 데이터가 있다면 실전에서는 충분히 낮은 오차로 수렴함.
*   **랜덤 시드(Random Seed) 고정의 중요성:**
    *   가중치 초기화(Weight Initialization)와 데이터 분할(Splitting) 등에는 무작위성이 포함됨.
    *   실험의 재현성을 확보하고, 하이퍼파라미터 변경(예: 학습률 조정)에 따른 성능 변화를 정확히 파악하기 위해 랜덤 시드를 고정해야 함.
    *   단, 시드를 고정해도 코드 내에서 난수 생성 함수를 호출하는 순서에 따라 결과가 달라질 수 있음을 유의해야 함.

**2. 오버피팅(Overfitting)과 데이터셋 크기**
*   **검증 데이터(Validation Set):** 전통적으로는 오버피팅 방지를 위해 사용함.
*   **대규모 데이터셋의 경우:** 데이터가 수백만 개 단위로 매우 클 경우, 오버피팅보다 언더피팅(Underfitting)이 더 문제일 수 있음. 이 경우 검증셋을 따로 두기보다 최대한 많은 데이터를 사용하여 길게 학습시키는 것이 더 나은 성능을 보일 수 있음.

**3. 학습 모범 사례 및 정규화(Regularization)**
*   **데이터 처리:** 데이터 중심화(Centering), 미니 배치(Mini-batch) 사용 권장.
*   **드롭아웃(Dropout):**
    *   학습 중 임의의 뉴런을 확률적으로 꺼버리는 기법.
    *   모델이 특정 뉴런에 과도하게 의존하는 것을 막아 일반화(Generalization) 성능을 높임.
*   **데이터 증강(Data Augmentation):**
    *   이미지를 회전, 반전, 자르기, 색상 변경 등을 통해 변형하여 '가상의' 학습 데이터를 생성.
    *   데이터의 의미(Semantics)는 유지하면서 데이터 양을 늘려 오버피팅을 방지하는 필수적인 기법.

**4. 전이 학습(Transfer Learning)**
*   **개념:** 대규모 데이터셋(예: ImageNet)으로 사전 학습된(Pre-trained) 모델의 가중치를 가져와 새로운 작업에 활용하는 것.
*   **방법:**
    *   초기 레이어(일반적인 특징 추출)는 고정(Freeze)하고, 후반부 레이어(작업 특화 특징)만 재학습하거나 미세 조정(Fine-tuning)함.
    *   데이터가 적을수록 더 많은 레이어를 고정하고, 데이터가 많거나 도메인이 다를수록 더 많은 레이어를 학습시킴.
*   **파운데이션 모델(Foundation Model):** 최근에는 사전 학습된 거대 모델을 파운데이션 모델이라 부르며, 이는 전이 학습의 개념과 일맥상통함.

**5. 시맨틱 세그멘테이션(Semantic Segmentation)과 U-Net**
*   **정의:** 이미지의 모든 픽셀을 각각 분류하여 객체를 분할하는 작업 (예: 의료 영상에서 병변 부위 파악).
*   **U-Net 구조:**
    *   세그멘테이션 분야의 표준 모델.
    *   완전 연결 계층(Fully Connected Layer) 없이 컨볼루션(Convolution)으로만 구성됨.
    *   **스킵 연결(Skip Connection):** 인코더(압축) 단계의 정보를 디코더(복원) 단계로 직접 전달하여 디테일을 보존함.

**6. 적대적 공격(Adversarial Attacks)**
*   **개념:** 인간의 눈에는 보이지 않는 미세한 노이즈(Perturbation)를 이미지에 추가하여 모델이 오답을 내도록 유도하는 것.
*   **원리:** 모델의 가중치를 업데이트하는 것이 아니라, 오차를 최대화하거나 특정 오답 클래스로 유도하도록 **입력 이미지의 픽셀값**을 업데이트함.
*   **의미:** 신경망 모델이 미세한 변화에도 취약할 수 있음을 보여줌.
