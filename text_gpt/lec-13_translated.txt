지금 우리가 이야기하고 있는 것은 분류기(classifier)입니다. 첫 번째로 봤던 것은 KNN, K-Nearest Neighbor였죠. 이것도 분류기이긴 한데, 이제는 선형 분류기(linear classifier)를 살펴볼 겁니다. 선형 분류기는 기본적으로 서로 다른 클래스들을 나누는 직선을 찾는 과정이라고 보면 됩니다.

클래스를 나눈다는 게 무슨 의미냐 하면, 특징(feature), 여기서는 X라고 부르는 값을 어떤 벡터와 곱하는 겁니다. 이 X는 2차원 특징 공간의 점이라고 생각하면 되고, 여기에 어떤 다른 벡터를 곱해 주면 그 벡터가 직선의 모양을 결정하게 됩니다. 이 둘의 내적을 구해서 부호(sign)를 보면, 직선의 왼쪽에 있는 점들은 음수, 오른쪽에 있는 점들은 양수가 되어서 데이터를 둘로 나누게 되는 거죠.

예제로 든 데이터는 X1, X2라는 두 개의 특징을 가진 2차원 데이터이고, 여기를 나누는 직선을 하나 찾고자 합니다. 아까 예로 들었던 것 중 하나가 W1=1, W2=0인 경우였어요. 이건 사실 “X1이 양수냐 음수냐”만 보고 나누는 겁니다. X1이 양수면 한쪽(예: 양성 클래스), 음수면 반대쪽(예: 음성 클래스)으로 분류하는 거죠. 여기서 실제로 양수/음수 자체가 고양이/강아지 같은 의미를 가지진 않고, 단지 두 개의 클래스를 구분하는 기호라고 생각하면 됩니다.

그렇다면, 직선을 정확히 어떻게 정의할까요? 우리가 지금까지 보던 방식과는 약간 다릅니다. 먼저, 관심 있는 직선에 수직인 벡터로 직선을 정의하는 방식을 이야기할 겁니다. 이 직선은 우리가 그리고 싶은, 데이터를 나누는 그 직선과 같은 것이고, 이 직선을 정의(파라미터화)하는 방법은 다음과 같습니다.

먼저, y = -(A/C)x 라는 식을 생각해 봅시다. 이건 우리가 익숙한 기울기-절편(slope-intercept) 형태입니다. 여기서 -(A/C)가 기울기이고, 뒤에 상수항이 있으면 그게 절편이죠. 지금은 절편이 0이기 때문에 식에 나타나지 않습니다.

이 식을 조금 바꿔보면,
y = -(A/C)x 와 동치인 식이 AX + CY = 0 입니다. 양변에 C를 곱해 준 거죠. 이 식을 다시 벡터 내적 형태로 쓰면, A·X + C·Y = 0, 즉 [A, C]와 [X, Y]의 내적이 0인 형태입니다.

여기서 X축, Y축이 있다고 생각해 봅시다. 이 공간의 임의의 점을 하나 잡고, 그 점을 나타내는 벡터와 [A, C]라는 벡터의 내적을 계산했을 때 0이 되면, 그 점은 바로 우리가 말한 “직선” 위에 있는 점입니다. 내적이 0이라는 것은 두 벡터가 서로 90도, 즉 수직(perpendicular)이라는 의미죠.

정리하면, 벡터 X는 원점에서부터 어떤 점까지 이어지는 벡터라고 볼 수 있고, 이 벡터와 W = [A, C]라는 벡터의 내적이 0이면 X는 W에 수직입니다. 이 말은 곧, W에 수직인 모든 벡터들이 이루는 집합이 바로 직선이라는 뜻입니다. 즉, 직선 위의 모든 점(벡터)은 W와 수직이고, 따라서 W와 그 점의 내적은 0이 됩니다.

따라서, 우리는 직선을 “일정 차원을 가지는 벡터”로 정의하기 시작할 겁니다. 2차원 공간이면 W도 2차원 벡터이고, 파라미터가 두 개라는 뜻입니다. 정리하자면, W와의 내적이 0이 되는 모든 점들의 집합, 즉 W와 수직이 되는 모든 벡터 형식의 점들이 직선을 이룹니다. 그게 바로 이 직선입니다.

여러분의 목표는 이 W를 구성하는 변수들을 찾는 것입니다.

이제 직선을 어떤 방향으로든 평행이동해서 옮긴 경우를 생각해 봅시다. 이때는 절편이 추가되죠. 보통 -B/C 같은 형태가 됩니다. 식을 다시 쓰면, AX + CY + B = 0 과 같은 형태가 됩니다. 우리의 목표는 이때 A, B, C를 찾는 것입니다. 이 값들이 직선을 결정합니다. B는 상수항이라고 보면 되고, 이걸 다시 벡터 형태로 쓰면

WᵀX + B = 0

이 됩니다. B를 W에 포함해서 생각할 수도 있지만, 이 형태가 나중에 더 유용하기 때문에 이렇게 씁니다. 요컨대, WᵀX + B = 0 을 만족하는 점들의 집합이 바로 이 직선을 이룬다는 뜻입니다. 즉, 이 직선은 W라는 벡터와 오프셋 B로 정의됩니다.

이게 왜 중요할까요? 우리가 할 일은 어떤 점이 직선의 어느 쪽에 있는지를 판단하는 것입니다. 이건 단순히 WᵀX + B 값을 구한 뒤 부호를 보는 것으로 할 수 있습니다. 그러나 우리는 거기서 한 걸음 더 나아가고 싶습니다. “점이 직선에서 얼마나 떨어져 있는지”도 알고 싶습니다. 이 거리 D를 구하고 싶다는 거죠.

이 거리 D를 어떻게 구할까요? 사실 생각보다 간단합니다. 그림을 떠올려 봅시다. W라는 벡터가 있고, Q라는 점이 있습니다. Q에서 직선까지의 가장 짧은 거리(수선의 길이)가 D입니다. 이 D는 반드시 직선에 수직이면서 가장 짧은 거리, 즉 우리가 보통 “점과 직선 사이의 거리”라고 부르는 그 거리입니다.

먼저, 이 D를 어떻게 표현할지부터 정리해 봅시다. QP라는 벡터(화살표)는 점 Q에서 직선 위의 한 점 P까지 가는 벡터입니다. 이 벡터는 P - Q로 계산합니다. P와 Q는 좌표(점) 혹은 벡터라고 생각하면 됩니다.

표기에서 X₀, Y₀, X₁, Y₁ 이렇게 아래 첨자를 쓰는데, 이 “0”은 영어로 “zero”라고 읽어도 되지만, 수학에서는 종종 “낫(not)”이라고 발음하기도 해서 X-not 이런 식으로 부르기도 합니다. 그냥 인덱스라고 보면 됩니다.

W의 길이는 L2 노름(||W||₂)입니다. 그리고 D는 QP를 W에 사영(projection)한 길이입니다. 즉, QP를 W 방향으로 내려 비춘 그림자의 길이가 바로 D이고, 이 길이는 Q에서 직선까지의 거리와 같습니다.

사영의 공식은 다음과 같습니다. QP를 W에 사영했을 때의 길이 D는

D = (QP와 W의 내적) / (W의 길이)

입니다. (절댓값은 방향이 아닌 길이만 관심 있을 때 씁니다.)

이제 실제로 계산해 봅시다. QP는 (X₀ - X₁, Y₀ - Y₁) 같은 벡터입니다. 분모는 W의 길이이므로 √(A² + C²)입니다. 분자는 내적이므로,

A·(X₀ - X₁) + C·(Y₀ - Y₁)
= AX₀ + CY₀ - AX₁ - CY₁

이 됩니다.

여기서 중요한 사실 하나: Q는 직선 위의 점입니다. 따라서 Q = (X₁, Y₁)는 직선 AX + CY + B = 0 을 만족해야 합니다. 즉,

AX₁ + CY₁ + B = 0

입니다. 이 식을 B에 대해 정리하면,

B = - (AX₁ + CY₁)

이 되죠. 그런데 위에서 우리가 가지고 있던 -AX₁ - CY₁과 정확히 같으니, 이 부분을 B로 치환할 수 있습니다. 그러면 분자는

AX₀ + CY₀ + B

가 됩니다. 이건 바로 WᵀX₀ + B, 즉 직선 식에 X₀를 대입한 값과 같습니다.

결국, 점 X₀ = (X₀, Y₀)가 직선 WᵀX + B = 0 에서 떨어진 거리 D는

D = |WᵀX₀ + B| / ||W||

로 계산할 수 있습니다.

이제 “어떤 직선이 가장 좋은 직선이냐”라는 문제로 돌아갑시다. 여기서 “좋다”란 무엇을 의미하느냐를 먼저 정의해야 합니다. 직선 후보 A, B, C, D가 있다고 해봅시다. 제 생각에 A가 가장 좋아 보이는 이유는, 양성/음성 데이터 사이를 잘 가르면서 모든 점들로부터 직선까지의 거리가 최대가 되기 때문입니다. C 같은 경우는 직선이 데이터에 너무 붙어 있어서 새 점이 들어왔을 때 오분류할 가능성이 크죠. D는 간격이 너무 좁고, B와 C도 데이터 분포를 잘 반영하지 못합니다.

우리는 새로운 점이 들어왔을 때도 잘 일반화(generalization)되기를 원합니다. 그래서 “가장 여유 있게, 여유 있는 간격(margin)을 최대화하는 직선”이 좋다고 정의하게 됩니다.

여기서 유명한 SVM(Support Vector Machine)이 등장합니다. SVM은 이런 최적의 분리 초평면(optimal separating hyperplane)을 찾는, 판별적(discriminative) 분류기입니다.

지금까지는 2차원에서 직선을 그려 설명했지만, 실제로는 어떤 D차원에서도 같은 개념이 적용됩니다. 그 경우에는 직선이 아니라 초평면(hyperplane)이라고 부릅니다. 3차원에서는 평면, 4차원 이상에서도 ‘평면’이긴 한데, 고차원이어서 보통 하이퍼플레인이라고 이름을 붙입니다.

우리의 목표는 두 가지입니다.

1. 데이터를 선으로(혹은 초평면으로) 잘 분리한다.
2. 양성/음성 학습 샘플 사이의 마진(margin)을 최대화한다.

여기서 마진이란, 결정 경계(가운데 직선)로부터 양쪽 클래스의 가장 가까운 점까지의 거리, 그리고 그 두 거리의 합을 의미합니다. 그림으로 보면, 가운데 결정 경계가 있고, 그 양쪽에 서로 평행한 두 개의 ‘경계선’이 있습니다. 이 두 평행선 사이의 간격이 바로 마진입니다.

이 세 직선은 다음과 같이 정의할 수 있습니다.

- 가운데 직선: WᵀX + B = 0
- 한쪽 평행선: WᵀX + B = +1
- 반대쪽 평행선: WᵀX + B = -1

WᵀX + B = +1 위에 있는 점들이 양성 클래스 중에서 가장 경계에 가까운 점들이고, WᵀX + B = -1 위에 있는 점들이 음성 클래스 중 가장 경계에 가까운 점들입니다. 이 경계선 위에 있는 점들을 서포트 벡터(support vector)라고 부릅니다. 이 점들이 바로 결정 경계의 모양을 결정하는 점들입니다.

중요한 관점은, 우리가 먼저 WᵀX + B = 0을 정하고 그 후에 ±1 경계를 그리는 것이 아니라, 사실은 이 ±1 경계에 딱 올라탄 점들(서포트 벡터)의 조건을 만족하도록 W와 B를 찾고, 그 사이에 자연스럽게 WᵀX + B = 0이 결정된다고 보는 겁니다.

이제 마진 M을 수식으로 구해 봅시다. 마진은 가운데 직선에서 양성 서포트 벡터까지의 거리 + 가운데 직선에서 음성 서포트 벡터까지의 거리입니다. 두 거리는 서로 같으므로, 한쪽 거리의 두 배라고 생각해도 됩니다.

우리는 이미 “점에서 직선까지의 거리” 공식을 알고 있습니다:

D = |WᵀX + B| / ||W||

서포트 벡터들은 WᵀX + B = +1 또는 -1을 만족하는 점들이므로, 이 점들에 대해서는

D = |1| / ||W|| = 1 / ||W||

입니다. 양쪽 모두 1/||W|| 이므로, 전체 마진 M은

M = 2 / ||W||

가 됩니다.

따라서, 마진을 최대화하는 것은 ||W||를 최소화하는 것과 같습니다. 방향은 그대로 두고, 벡터 W의 길이(크기)를 줄이면 마진이 커지게 되죠. 직선을 정의할 때는 방향만 중요하고, 크기는 스케일일 뿐이지만, 여기서는 바로 이 크기가 마진 크기를 결정합니다.

요약하면, SVM의 핵심 목표는 다음과 같은 W(와 B)를 찾는 것입니다.

- 모든 양성 예제는 WᵀXᵢ + B ≥ +1
- 모든 음성 예제는 WᵀXᵢ + B ≤ -1
- 동시에 마진 2/||W||를 최대화(즉, ||W||를 최소화)

이 문제를 수학적으로 쓰면,

- 마진 최대화 ↔ ||W|| 최소화
- 그리고 모든 훈련 샘플 (Xᵢ, Yᵢ)에 대해 Yᵢ(WᵀXᵢ + B) ≥ 1

입니다. 여기서 Yᵢ는 클래스 레이블로, 양성은 +1, 음성은 -1입니다. 위 부등식을 한 줄로 쓰면

Yᵢ(WᵀXᵢ + B) ≥ 1  for all i

가 됩니다.

또 한 가지, 보통 ||W|| 대신 (1/2)||W||² 를 최소화하는 형태로 씁니다. 이유는 다음과 같습니다:

- ||W||가 커질수록 ||W||²도 단조 증가하고,
- ||W|| ≥ 0 이므로, 둘 중 어느 것을 최소화해도 결과는 같습니다.
- ||W||² = WᵀW 이고, 이게 이차식(quadratic)이어서 수학적으로 다루기 편합니다.

그래서 SVM의 기본 문제(하드 마진 SVM라고 부르는 형태)는 아래와 같은 최적화(optimization) 문제로 정리됩니다.

목표:
-  (1/2) WᵀW 를 최소화한다 (즉, ||W||²/2를 최소화)

제약 조건:
-  Yᵢ(WᵀXᵢ + B) ≥ 1, ∀ i

이런 식으로 “어떤 값을 최소화하면서 동시에 어떤 조건들을 만족하는 W와 B를 찾아라”라고 쓰인 문제를 제약 최적화(constraint optimization) 문제라고 부릅니다. 여기서 목적 함수(objective function)는 (1/2)WᵀW 이고, 제약식(constraint)은 Yᵢ(WᵀXᵢ + B) ≥ 1 입니다. 그리고 목적 함수에 W의 제곱항이 들어 있으므로 이걸 이차 최적화(quadratic optimization) 문제라고 부릅니다.

이 문제를 실제로 푸는 방법(라그랑주 승수, KKT 조건, 쿼드라틱 프로그래밍 솔버 등)은 또 다른 수학 분야이고, 여기서는 구체적인 알고리즘 대신 “이런 식으로 SVM이 문제를 정식화한다”는 점만 이해하면 됩니다.

일단 어떤 방법을 써서든 이 최적화 문제를 풀어 W*와 B*를 구했다고 합시다(별표는 최적해를 의미). 그러면 새로운 데이터 X가 들어왔을 때, 그 점의 클래스는

sign(W*ᵀX + B*)

의 부호로 예측합니다.

여기까지가 선형 SVM의 기본 형태이고, 이것만으로도 이미 흥미롭습니다. 하지만 SVM이 특히 재미있는 이유는 그 다음에 나오는 두 번째 성질 때문입니다.

성질 1: 해 W는 학습 데이터 (Xᵢ, Yᵢ)를 이용해 다음과 같은 형태로 표현할 수 있습니다.

W = Σᵢ αᵢ Yᵢ Xᵢ

여기서 αᵢ ≥ 0 입니다.

즉, 우리가 찾은 W는 모든 학습 데이터 Xᵢ의 “선형 결합(linear combination)”으로 표현될 수 있습니다. 각각의 Xᵢ에 레이블 Yᵢ(+1 또는 -1)를 곱하고, 거기에 어떤 계수 αᵢ를 곱해서 전부 더하면 W가 된다는 겁니다. 원래는 W를 직접 찾으려고 했는데, 사실은 “알파 αᵢ들만 잘 정하면 W를 표현할 수 있다”는 것이죠.

성질 2: αᵢ > 0 인 경우는 오직 서포트 벡터들에 대해서만 해당됩니다. 즉,

- 서포트 벡터(Xᵢ가 ±1 경계선 위에 있는 점)들에 대해서는 αᵢ > 0
- 나머지 모든 점들에 대해서는 αᵢ = 0

입니다.

따라서, 실제로는

W = Σ (서포트 벡터 i에 대해서만) αᵢ Yᵢ Xᵢ

라고 쓸 수 있습니다. 즉, 우리가 찾은 결정 경계 W는 오직 서포트 벡터들만의 선형 결합으로 표현됩니다. 다른 모든 학습 점들은 αᵢ = 0이므로 W를 결정하는 데 기여하지 않습니다. 이게 바로 “서포트 벡터 머신”이라는 이름의 이유입니다. 결정 경계는 서포트 벡터들만으로 완전히 결정됩니다.

이제 예측 함수로 돌아와 봅시다. 원래는

f(X) = sign(WᵀX + B)

였는데, 여기에 W = Σᵢ αᵢ Yᵢ Xᵢ 를 대입하면,

WᵀX = (Σᵢ αᵢ Yᵢ Xᵢ)ᵀ X
     = Σᵢ αᵢ Yᵢ (Xᵢᵀ X)

이 됩니다. 따라서 새로운 점 X에 대한 예측식은

f(X) = sign( Σᵢ αᵢ Yᵢ (Xᵢᵀ X) + B )

가 됩니다.

여기서 중요한 점:

- 더 이상 W를 따로 계산해서 저장할 필요가 없습니다.
- 대신, “서포트 벡터들 Xᵢ, 계수 αᵢ, 레이블 Yᵢ, 그리고 상수 B”만 알면 됩니다.
- 새 데이터 X가 들어올 때마다, X와 모든 서포트 벡터들 사이의 내적(XᵢᵀX)을 계산해서 그 합의 부호를 보면 됩니다.

직관적으로 보면 이렇습니다.

- 각 서포트 벡터 Xᵢ는 자신의 클래스 Yᵢ(+1 또는 -1)와 함께 붙어 있습니다.
- X와 Xᵢ의 내적 XᵢᵀX는 X가 Xᵢ와 얼마나 비슷한지(가까운지)를 나타내는 척도입니다.
  - 비슷하고 가까우면 값이 크고,
  - 멀면 값이 작습니다.
- Σᵢ αᵢ Yᵢ (XᵢᵀX) 는 “X가 양성 서포트 벡터들 쪽에 더 가까운지, 음성 서포트 벡터들 쪽에 더 가까운지”를 일종의 가중 합으로 계산하는 것입니다.
- 최종 부호가 +면 양성, -면 음성으로 분류합니다.

즉, 처음에는 “직선을 그려서 그 직선으로부터 어느 쪽에 있는지” 보고 싶다고 시작했지만, 실제 구현은 “서포트 벡터들과의 유사도(내적)를 이용해 투표하는 방식”으로 동작하게 됩니다. 이 형태를 SVM의 이중(dual) 형태라고 부릅니다.

하지만 여기에는 한 가지 큰 문제가 있습니다. “데이터가 선형으로 분리(linearly separable) 불가능한 경우는 어떻게 할 것인가?”입니다. 선형으로 분리 가능하다는 것은, 하나의 초평면으로 두 클래스를 완벽하게 나눌 수 있다는 의미입니다.

현실의 많은 데이터는 그렇지 않습니다. 예를 들어 1차원 공간을 생각해 봅시다. 숫자 선 위에 점들이 양성/음성으로 섞여 있을 때, 하나의 임계값(직선)을 잡아 둘을 완벽히 나누지 못하는 경우가 생깁니다. 이런 데이터를 2차원으로 매핑해서(예: x를 x와 x²로 바꾸는 식으로) 보면, 비선형 경계가 선형 경계로 바뀌기도 합니다. 이런 아이디어를 일반화한 것이 “커널 트릭(kernel trick)”입니다.

핵심 아이디어는 이렇습니다.

1. 원래의 입력 X를 어떤 고차원 특징 공간으로 보내는 변환 φ(X)를 정의합니다. (예: X → [X, X²], 혹은 더 복잡한 다항식, 가우시안 등)
2. 그 고차원 공간에서 선형 SVM을 그대로 적용합니다. 즉, 내적 Wᵀφ(X)를 가지고 분류합니다.
3. 하지만 직접 φ(X)를 계산하고 고차원에서 내적을 구하면 계산량이 너무 커지므로, “φ(Xᵢ)ᵀφ(Xⱼ)”라는 내적을 직접 계산하지 않고도 그 값을 바로 주는 함수 K(Xᵢ, Xⱼ)를 정의합니다.
4. 이 함수를 커널(kernel)이라고 부르고, K(X, Y) = φ(X)ᵀφ(Y) 를 만족하는 함수입니다.

예를 들어, 간단한 예시로

φ(X) = [X, X²]  
φ(Y) = [Y, Y²]

라고 했을 때, 두 벡터의 내적은

φ(X)ᵀφ(Y) = X·Y + X²·Y²

가 됩니다. 이걸 굳이 “먼저 φ(X), φ(Y)를 구해서 2차원에서 내적한다”라고 생각하지 않고, 그냥 “입력 X와 Y를 받아 바로 XY + X²Y²를 반환하는 함수”로 만들어 쓰면 됩니다. 이게 커널의 기본 예시입니다.

이제 SVM의 이중 형태로 돌아가 봅시다. 우리가 본 이중 문제는 대략 이런 꼴입니다.

- αᵢ들을 변수로 하는 어떤 목적 함수를 최대화
- 제약 조건: αᵢ ≥ 0, Σᵢ αᵢYᵢ = 0
- 목적 함수 안에는 Σᵢ αᵢ, Σᵢⱼ αᵢαⱼYᵢYⱼ (XᵢᵀXⱼ) 같은 항들이 포함됩니다.

여기서 주목할 점은, 이중 문제 안에는 XᵢᵀXⱼ 같은 “입력들 사이의 내적”만 등장한다는 것입니다. 따라서, 우리가 φ(X)라는 고차원 매핑을 도입하면, 이 내적은 모두 φ(Xᵢ)ᵀφ(Xⱼ)로 바뀝니다. 그런데 φ(Xᵢ)ᵀφ(Xⱼ) = K(Xᵢ, Xⱼ)이므로, 실제 계산에서는

- 원래의 Xᵢ, Xⱼ만 보고
- 커널 함수 K(Xᵢ, Xⱼ)만 호출하면,

마치 고차원 공간에서 φ(Xᵢ), φ(Xⱼ)의 내적을 한 것과 똑같은 효과를 얻을 수 있습니다. φ 자체를 직접 계산하거나, 고차원 벡터를 다루지 않아도 됩니다. 이게 바로 커널 트릭입니다.

예측식도 마찬가지입니다. 선형 SVM에서는

f(X) = sign( Σᵢ αᵢ Yᵢ (Xᵢᵀ X) + B )

였다면, 커널 SVM에서는

f(X) = sign( Σᵢ αᵢ Yᵢ K(Xᵢ, X) + B )

가 됩니다. 여기서 K는 예를 들어 다음 중 하나일 수 있습니다.

- 선형 커널: K(X, X′) = XᵀX′  (사실상 선형 SVM과 동일)
- 다항식 커널: K(X, X′) = (XᵀX′ + c)ᵈ
- RBF(가우시안) 커널: K(X, X′) = exp(-||X - X′||² / (2σ²))
- 기타 등등

이렇게 하면, 입력 공간에서는 비선형인 결정 경계를, 어떤 고차원 특징 공간에서는 선형 초평면으로 표현할 수 있고, 우리는 그 고차원 공간을 명시적으로 다루지 않고도 SVM을 그대로 적용할 수 있습니다.

정리하자면:

1. 선형 분류기는 WᵀX + B로 직선을 정의해서 두 클래스를 나눈다.
2. 점과 직선 사이의 거리는 |WᵀX + B| / ||W|| 로 계산할 수 있다.
3. SVM은 “두 클래스를 완벽히 나누면서 마진 2/||W||를 최대화하는 W, B”를 찾는 이차 최적화 문제로 정식화된다.
4. 해 W는 학습 데이터 Xᵢ와 레이블 Yᵢ의 선형 결합으로 표현할 수 있고, 그중에서도 서포트 벡터에 대응하는 항들만 실제로 남는다(αᵢ>0).
5. 따라서 예측은 “서포트 벡터들과의 내적(유사도)에 기반한 가중 합의 부호”로 이뤄진다.
6. 선형으로 분리 불가능한 경우에는 입력을 고차원 특징 공간으로 매핑하고, 그 공간에서 선형 SVM을 적용한다.
7. 이때 직접 고차원 내적을 계산하는 대신, 커널 함수 K(X, X′)를 이용해 φ(X)ᵀφ(X′)를 바로 계산하는 방식으로 효율성을 확보한다. 이것이 커널 트릭이다.
