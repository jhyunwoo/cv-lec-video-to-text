### **강의 내용 요약: 딥러닝 학습 전략 및 최신 모델 동향**

#### **1. 학습 알고리즘 및 실용적 고려사항 (Practical Matters on Training)**
*   **수렴 및 손실(Loss):** 학습 오차(Training Error)가 항상 0이 되지는 않으며, 국소 최적해(Local Optima)에 빠지거나 진동(Oscillate)할 수 있음. 실제로는 적절한 하이퍼파라미터 설정 시 낮은 오차로 수렴함.
*   **무작위성(Randomness) 통제:**
    *   가중치 초기화(Weight Initialization)와 데이터 분할(Splitting)의 무작위성 때문에 실행할 때마다 결과가 달라질 수 있음.
    *   실험의 변수를 통제하기 위해 **랜덤 시드(Seed)를 고정**하는 것이 중요함.
    *   *주의:* 시드를 고정하더라도 코드 내의 랜덤 함수 호출 순서 등에 따라 여전히 미세한 차이가 발생할 수 있음을 인지해야 함.

#### **2. 과적합(Overfitting)과 데이터 규모**
*   **전통적 관점:** 과적합을 방지하기 위해 검증 데이터셋(Validation Set)을 사용하여 학습 중단 시점을 결정함.
*   **대규모 데이터 관점:** 수백만 장 이상의 매우 큰 데이터셋을 사용할 때는 과적합보다 과소적합(Underfitting)이 더 문제되는 경우가 많음. 이 경우 검증 셋을 따로 두기보다 **최대한 많은 데이터를 사용하여 오래 학습**시키는 것이 성능 향상에 유리할 수 있음.

#### **3. 주요 정규화 및 성능 향상 기법**
*   **드롭아웃(Dropout):**
    *   학습 과정에서 임의의 뉴런을 일정 확률로 비활성화(Turn off)하는 기법.
    *   특정 뉴런이나 경로에 과도하게 의존하는 것을 방지하여 모델의 일반화(Generalization) 성능을 높임.
*   **데이터 증강(Data Augmentation):**
    *   이미지의 의미(Semantics)를 해치지 않는 선에서 기하학적 변형(회전, 반전, 크롭, 색상 변경 등)을 가해 가상의 학습 데이터를 생성함.
    *   데이터의 다양성을 확보하여 과적합을 막는 데 매우 필수적인 기법.

#### **4. 전이 학습 (Transfer Learning)**
*   **개념:** 대규모 데이터셋(예: ImageNet)으로 미리 학습된(Pre-trained) 모델의 가중치를 가져와, 데이터가 적은 새로운 작업에 재사용하는 방법.
*   **방법 (Fine-tuning):**
    *   초기 레이어(일반적인 특징 추출)는 가중치를 고정(Freeze)하고, 후반부 레이어(작업 특화)만 학습시키는 방식이 일반적임.
    *   데이터가 많고 도메인이 다를수록 더 많은 레이어를 학습시킴.
*   **파운데이션 모델(Foundation Model):** 최근 언급되는 파운데이션 모델은 본질적으로 범용적인 목적을 위해 대규모로 '사전 학습된 모델(Pre-trained Model)'과 동일한 개념임.

#### **5. 시맨틱 세그멘테이션 (Semantic Segmentation) - U-Net**
*   **정의:** 이미지의 모든 픽셀을 각각의 클래스로 분류하는 작업 (단순 객체 탐지를 넘어 픽셀 단위 의미 파악).
*   **U-Net 구조:**
    *   의료 영상 분석 등에서 표준처럼 사용되는 아키텍처.
    *   완전 연결 계층(Fully Connected Layer)이 없고 합성곱(Convolution)으로만 구성된 완전 합성곱 신경망(FCN).
    *   알파벳 'U'자 모양의 구조로, 인코더의 정보를 디코더로 직접 전달하는 **스킵 연결(Skip Connection)**을 사용하여 위치 정보와 특징 정보를 결합함.

#### **6. 적대적 예제 (Adversarial Examples/Attacks)**
*   **개념:** 인간의 눈에는 보이지 않는 미세한 노이즈(Perturbation)를 이미지에 추가하여, CNN 모델이 엉뚱한 클래스로 오분류하도록 유도하는 공격.
*   **원리:** 모델의 가중치를 업데이트하는 대신, **입력 이미지의 픽셀 값 자체를 업데이트**하여 오차를 최대화하거나 특정 오답 클래스의 확률을 높이는 방향으로 조작함.
*   이는 딥러닝 모델이 미세한 픽셀 변화에도 취약할 수 있음을 보여줌.
