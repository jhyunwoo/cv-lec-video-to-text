### 강의 요약: 분류기 및 서포트 벡터 머신 (SVM)

#### 1. 선형 분류기 (Linear Classifier)의 기초
*   **개념:** 특징 공간(Feature Space)에서 데이터를 두 개의 클래스(Positive/Negative)로 나누는 직선(또는 초평면, Hyperplane)을 찾는 것.
*   **결정 경계의 정의:**
    *   벡터 $W$와 특징 $X$의 내적(Inner Product)에 편향(Bias) $B$를 더한 형태: $W^TX + B = 0$.
    *   $W$는 결정 경계(직선)에 수직인 법선 벡터(Normal Vector)이며, 직선의 방향을 결정함.
*   **분류 방법:** $W^TX + B$의 결과값의 부호(Sign)가 양수인지 음수인지에 따라 클래스를 판별.

#### 2. 거리 측정과 마진 (Distance and Margin)
*   **점과 직선 사이의 거리:**
    *   특정 점 $X$에서 결정 경계까지의 최단 거리 $D$는 다음과 같이 계산됨:
        $$D = \frac{|W^TX + B|}{||W||}$$
*   **좋은 분류기의 조건:**
    *   데이터를 단순히 나누는 것뿐만 아니라, 데이터 포인트들과 결정 경계 사이의 거리(마진, Margin)를 최대화하는 선이 가장 좋은 모델(일반화 성능이 좋음)임.
*   **서포트 벡터 (Support Vectors):**
    *   결정 경계와 가장 가까이 있는 데이터 포인트들.
    *   이 점들이 실질적으로 경계선의 위치와 모양을 결정함.

#### 3. 서포트 벡터 머신 (SVM)의 최적화
*   **SVM의 목표:**
    1.  데이터를 올바르게 분류해야 함 (제약 조건: $y_i(W^TX_i + B) \ge 1$).
    2.  마진을 최대화해야 함.
*   **최적화 문제 (Optimization Problem):**
    *   마진($M = \frac{2}{||W||}$)을 최대화하는 것은 $||W||$(W의 길이)를 최소화하는 것과 같음.
    *   따라서, SVM은 제약 조건을 만족하면서 $\frac{1}{2}||W||^2$을 최소화하는 **2차 최적화 문제(Quadratic Optimization Problem)**로 정식화됨.

#### 4. SVM의 Primal Form과 Dual Form
*   **Primal Form:** $W$와 $B$를 직접 구하는 기본 형태.
*   **Dual Form:**
    *   최적해 $W$는 데이터 포인트들의 선형 결합으로 표현 가능함 ($W = \sum \alpha_i y_i X_i$).
    *   중요한 속성: **서포트 벡터가 아닌 점들의 $\alpha_i$ 값은 0**임. 즉, $W$는 오직 서포트 벡터들에 의해서만 정의됨.
    *   새로운 데이터 예측 시, $W$를 직접 구할 필요 없이 서포트 벡터들과의 내적만으로 판별 가능.

#### 5. 비선형 SVM과 커널 트릭 (Kernel Trick)
*   **비선형 분리 문제:**
    *   원래 차원에서는 선형적으로 분리할 수 없는 데이터(예: 원형 분포, XOR 등)가 존재함.
*   **해결책 (고차원 매핑):**
    *   데이터를 더 높은 차원으로 매핑($\Phi(X)$)하면 선형 분리가 가능해짐.
*   **커널 트릭 (Kernel Trick):**
    *   고차원으로 매핑 후 내적을 수행하는 과정($\Phi(X_i)^T \Phi(X_j)$)은 계산 비용이 매우 높음.
    *   직접 매핑 함수를 계산하지 않고, 입력 공간에서 바로 고차원 공간의 내적 값을 계산해주는 **커널 함수($K(X_i, X_j)$)**를 사용.
    *   이를 통해 복잡한 비선형 분류 문제를 효율적으로 해결 가능.
