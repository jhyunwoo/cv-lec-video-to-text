제공해주신 강의 내용은 **비선형 SVM(Non-linear SVM), 커널 트릭(Kernel Trick), Soft Margin, 그리고 k-NN과의 비교**를 다루고 있습니다. 주요 핵심 내용을 요약해 드립니다.

### 1. 비선형 SVM과 특징 맵핑 (Non-linear SVM & Feature Mapping)
*   **기본 개념:** SVM은 기본적으로 선형(linear) 분류기입니다. 선형적으로 분리 불가능한 데이터를 분류하기 위해, 데이터를 **고차원 공간(Higher dimensional space)**으로 맵핑하는 함수 $\phi(x)$를 사용합니다.
*   **목표:** 원래 차원에서는 분리할 수 없던 데이터를 고차원에서는 선형 평면(Hyperplane)으로 분리할 수 있게 만드는 것입니다.

### 2. 커널 트릭 (Kernel Trick)의 중요성
*   **고차원 계산의 문제:** 데이터를 실제로 고차원으로 맵핑하면 차원이 커질수록(예: 10차원 → 100차원 → 무한대) 계산량(복잡도)이 급격히 증가합니다.
*   **커널의 역할:** 고차원 공간에서의 내적(Inner product, $\phi(x_i)^T \phi(x_j)$)을 굳이 데이터를 변환하지 않고도, 원래 차원의 입력값만으로 계산해내는 함수(Kernel function)를 사용합니다.
*   **Dual Form과 효율성:**
    *   SVM의 Primal Form($w$를 구함)과 Dual Form($\alpha$를 구함)은 등가입니다.
    *   Dual Form은 데이터 포인트 간의 **내적**에 의존하는데, 커널 트릭을 쓰면 복잡한 매핑 없이 이 값을 구할 수 있습니다.
    *   **Pre-computation:** 최적화 과정은 반복적(Iterative)이지만, 데이터 간의 커널 값(내적 값)은 변하지 않으므로 미리 계산(Matrix 형태)하여 저장해두면 연산 속도를 크게 높일 수 있습니다.

### 3. 주요 커널의 종류
*   **Linear Kernel:** 기본적인 내적.
*   **Polynomial Kernel:** 다항식 형태. 실제로 고차원 확장을 하지 않아도, 수식적으로 동일한 결과를 낮은 비용으로 계산 가능합니다.
*   **Gaussian RBF (Radial Basis Function) Kernel:**
    *   데이터를 **무한 차원(Infinite dimensional space)**으로 맵핑하는 효과를 냅니다.
    *   실제 무한 차원 계산은 불가능하므로, 커널 트릭을 통해서만 구현 가능합니다.
    *   가장 강력하고 널리 쓰이는 커널 중 하나입니다.

### 4. Soft Margin SVM
*   **Hard Margin의 한계:** 모든 데이터를 완벽하게 분류하려 하면, 이상치(Outlier) 때문에 결정 경계가 왜곡되거나 해를 찾을 수 없습니다.
*   **Slack Variable ($\xi$):** 일부 데이터가 마진을 위반하거나 오분류되는 것을 허용하는 변수입니다.
*   **하이퍼파라미터 C:**
    *   **C가 클 때:** 매우 엄격함. 오류를 허용하지 않으려 함 (Overfitting 위험).
    *   **C가 작을 때:** 관대함. 오류를 어느 정도 허용하며 마진을 넓힘.

### 5. 일반화 (Generalization)와 파라미터 영향
*   **모델의 목표:** 훈련 데이터를 완벽하게 나누는 것이 아니라, **새로운(보이지 않는) 데이터를 잘 분류**하는 것입니다.
*   **RBF 커널의 Gamma ($\gamma$):**
    *   값이 너무 크면 각 포인트 주변으로 좁은 결정 경계가 생겨 과적합(Overfitting)이 발생합니다.
    *   적절한 값을 찾아야 일반화 성능이 좋아집니다.

### 6. 선형 분류기(SVM) vs. k-NN 비교
*   **Linear Classifier (SVM):**
    *   **장점:** 테스트 시 속도가 매우 빠름 (저장된 $w$ 벡터와 내적만 하면 됨), 모델 크기가 작음.
    *   **단점:** 학습 시간이 오래 걸릴 수 있음, 적절한 커널과 파라미터를 찾아야 함.
*   **Nearest Neighbors (k-NN):**
    *   **장점:** 구현이 간단함, 클래스 개수에 상관없이 작동, 비선형 경계를 자연스럽게 형성.
    *   **단점:** 테스트 시 모든 데이터와 거리를 비교해야 하므로 속도가 느림, 모든 데이터를 저장해야 하므로 메모리 소모가 큼.
