### 강의 요약: 신경망(Neural Networks)의 기초와 구조

**1. 전통적 방식 vs 딥러닝 (Traditional vs Deep Models)**
*   **전통적 접근 (Shallow Models):** SIFT와 같은 특징(feature)을 사람이 직접 설계(handcrafting)한 후, SVM이나 KNN 같은 분류기를 별도로 학습시키는 방식. 특징 추출과 분류가 분리되어 있어 최적의 분류 성능을 내기에 한계가 있음.
*   **신경망 접근 (Deep Models):** 입력(픽셀)부터 출력(분류)까지 전체 과정을 하나의 파이프라인으로 연결하여 학습하는 **End-to-End** 방식. 모든 레이어가 공동으로(jointly) 학습되며, 앞단 레이어의 출력이 다음 레이어의 입력이 되는 계층적 구조를 가짐.

**2. 퍼셉트론 (Perceptron)과 선형 변환**
*   신경망의 가장 원시적인 형태.
*   입력 벡터($X$)에 가중치($W$)를 곱하고 편향($b$)을 더하는 선형 결합 형태 ($\sum W_i X_i + b$).
*   이는 기존의 선형 분류기(Linear Classifier)나 SVM의 선형 커널과 본질적으로 동일한 연산임.

**3. 비선형 활성화 함수 (Non-linear Activation Function)**
*   단순한 선형 변환만으로는 복잡한 데이터를 모델링하는 데 한계가 있으므로 비선형 함수를 도입함.
*   **시그모이드 (Sigmoid):** 입력을 $0$과 $1$ 사이의 값으로 압축(squash)하는 함수.
    *   출력이 $0$ 또는 $1$에 가까워지도록 유도하여, 이진 분류(Binary Classification)의 확률/신뢰도(confidence)로 해석하기 용이함.

**4. 신경망의 일반화와 행렬 표현**
*   **다층 구조:** 퍼셉트론을 여러 개 쌓아 입력($X$)을 은닉층($Z$, hidden representation)으로, 다시 출력($Y$)으로 변환.
*   **행렬 연산:** 아무리 복잡하고 깊은 신경망이라도 각 레이어의 연산은 가중치 행렬($W$)과의 곱으로 표현 가능함.
*   **파라미터 ($\theta$):** 전체 모델은 학습 가능한 파라미터(가중치 $W$, 편향 $b$)의 집합인 $\theta$로 표현됨 ($Y = f(X; \theta)$).

**5. 다중 클래스 분류 (Multi-class Classification)**
*   **레이블 인코딩:** 클래스를 $1, 2, 3$과 같은 정수로 표현하면 순서나 크기의 의미가 부여되므로, 이를 방지하기 위해 **원-핫 벡터(One-hot vector)** 방식을 사용 (예: $[0, 1, 0]$).
*   **소프트맥스 (Softmax):** 다중 출력 값을 확률 분포로 변환하는 함수.
    *   각 클래스의 점수(Logits)를 지수화(exponentiate)한 뒤, 전체 합으로 나누어 모든 출력의 합이 $1$이 되도록 함. 정답 클래스의 확률은 높이고 나머지는 낮추는 역할.

**6. 손실 함수 계산 예시 (Loss Calculation)**
*   강의 후반부에는 구체적인 수치를 들어 손실(Loss)을 계산하는 과정을 설명함.
*   **계산 방식:** 정답 클래스의 점수와 오답 클래스의 점수를 비교.
    *   (오답 점수 - 정답 점수 + 마진 1)이 0보다 크면 손실로 간주하여 합산함 (SVM의 Hinge Loss와 유사한 방식의 예시를 듬).
    *   정답 점수가 오답 점수보다 충분히 크다면(마진 이상), 해당 데이터의 손실(Loss)은 0이 됨.
